# Dataset

The canonical split files are JSONL with one dataset record per line. Each record follows [`example-schema.json`](example-schema.json), and its `target_report` follows [`schema.json`](schema.json). Preprocessing converts these records into the trainer's `{ "input": ..., "output": ... }` form. Training, validation, test, and evaluation benchmark splits are separate; never copy benchmark records into training data.

The active corpus currently contains 41 train, 10 validation, and 9 test examples (60 total, incorporating `pilot.jsonl` and Batch 2), expanding towards a target of 84 train, 18 validation, and 18 test examples (120 total). Historical flat legacy splits are archived in [`legacy/`](legacy/). Read [the dataset contribution guide](../docs/dataset-guide.md) before adding examples. Use only synthetic or permissioned, anonymized examples. Run `python training/validate_data.py` and `python training/preprocess.py`; automated validation/redaction is not a privacy guarantee.
