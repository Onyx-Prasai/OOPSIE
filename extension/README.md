# OOPSIE Browser Extension

This directory contains the Manifest V3 browser extension for OOPSIE.

## Setup Instructions
1. Open Google Chrome or Brave and go to `chrome://extensions/`.
2. Turn on **Developer mode** in the top-right toggle.
3. Click **Load unpacked**.
4. Select this folder (`/extension`).
5. Highlight any error text on Vercel, Netlify, or GitHub, right-click, and select **Analyze Error with OOPSIE**.
